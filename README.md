# 내 친구가 연락이 안돼

레딧 r/nosleep 괴담 「내 친구가 연락이 안돼」 전용 몰입형 리더.

- 본문과 사진은 저장소에 들어 있지 않다. 처음 한 번 docx 파일을 열면 그 브라우저가 기억한다.
- 로컬에서는 같은 폴더에 `story.docx`를 두고 `python -m http.server`로 열면 바로 읽힌다 (`.gitignore`로 제외).
- 단톡은 말풍선, Dean의 "이리와."는 알림과 화면 번쩍임, 글 속 진동/노크/끄는 소리/뚝뚝 소리는 Web Audio로 직접 합성.
- 5편부터 화면 가장자리에 곰팡이 줄기가 자란다.
- 스페이스: 자동 스크롤, 오른쪽 아래 설정에서 편 이동/소리/글자 크기.
